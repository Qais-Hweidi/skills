# Explain

Teach the concept by building a throwaway web page for a visual learner, then opening it.

Lead with drawings, boxes, arrows, timelines, state changes — and write the text that makes them land. Make it interactive, so clicking or dragging reveals cause and effect.

Compare only when the concept is defined by a contrast (X vs Y, with vs without). Otherwise just show the thing.

Be brief. Fewer sections, less text per section, no recaps or filler.

Build one self-contained HTML file, no dependencies. Verify anything you are unsure of. Reply with the path and a one-line outline per section.
