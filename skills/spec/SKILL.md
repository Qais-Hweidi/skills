# Spec

Define the goal, required behavior, constraints, and acceptance criteria clearly enough to implement and verify.

Base the design on current needs. Prefer the simplest approach that satisfies them, and add complexity only when existing requirements justify it. Do not design for hypothetical future needs.

When something is removed or unnecessary, remove it from the specification completely. Do not mention its removal.
